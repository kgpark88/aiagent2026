# 04. 도입 가이드

## 설치

- 사전 빌드 바이너리: [Releases](https://github.com/nashsu/llm_wiki/releases) — macOS(.dmg), Windows(.msi), Linux(.deb/.AppImage).
- 소스 빌드: Node.js 20+, Rust 1.70+ → `npm install` → `npm run tauri dev` / `npm run tauri build`.
- Chrome 확장: `chrome://extensions` → 개발자 모드 → Load unpacked → `extension/`.

## 빠른 시작

1. 새 프로젝트 생성(시나리오 템플릿: Research/Reading/Personal/Business/General).
2. Settings에서 LLM provider 설정(API key + model).
3. (선택) Web Search provider·소스 폴더 자동 감시 설정.
4. Sources에서 문서 가져오기 → Activity Panel에서 위키 자동 생성 확인.
5. Chat으로 질문, Knowledge Graph로 연결 탐색, Review 처리, 주기적 Lint.

## 프로젝트 구조

```plaintext
my-wiki/
├── purpose.md     # 목표·핵심 질문·연구 범위
├── schema.md      # 위키 구조 규칙·페이지 타입
├── raw/sources/   # 업로드 문서(불변)
├── wiki/
│   ├── index.md · log.md · overview.md
│   ├── entities/ · concepts/ · sources/
│   ├── queries/  · synthesis/ · comparisons/
├── .obsidian/     # Obsidian vault 설정(자동)
└── .llm-wiki/     # 앱 설정·채팅·리뷰 항목
```

## 적용 사례

개인 성장 기록, 장기 리서치, 책 읽기(캐릭터·테마 위키), 팀 내부 위키(Slack·회의록), 경쟁 분석·실사·여행 계획·강의 노트 등 "시간에 걸쳐 지식을 쌓는" 모든 곳.
